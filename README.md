# Singh Backyard 3D

Concept 3D model of the backyard (no pool), built from the landscape plans V4-2.

- `index.html` - 3D viewer, works on iPhone, Android and computers.
- `ar/` - viewer with the AR button.

Materials and sky: Poly Haven (CC0). Viewers: three.js (MIT), model-viewer (BSD-3-Clause).
